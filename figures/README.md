# Figures

This folder contains selected visualizations generated during the project.

## Included Figures

* Protein domain architecture analysis using InterPro
* BLAST non-homology analysis against Homo sapiens
* Protein-ligand docking interaction analysis
* Residue level RMSF-based protein flexibility analysis
* HOMO-LUMO molecular orbital analysis of ligand 172943871

These figures summarize the major computational analyses performed during the study and support the identification of potential glucokinase inhibitors against Naegleria fowleri.
