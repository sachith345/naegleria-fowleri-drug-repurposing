# Project Report

This folder contains the final report for the project:

**Rifampin Analogs as Potential Inhibitors of Glucokinase from Naegleria fowleri in Primary Amoebic Meningoencephalitis: An In-Silico Approach**

## Summary

The study employed an integrated computational workflow involving:

* Protein sequence analysis
* Functional annotation
* Molecular docking
* ADMET profiling
* Protein flexibility analysis
* DFT-based molecular orbital analysis

The report documents the abstract, introduction, literature survey, materials and methodology, results, conclusion, references, and appendix generated during the project.
