# Results

This folder contains the major computational outputs generated during the project.

## Files

### docking_results.xlsx

Contains molecular docking scores and binding affinity values obtained from virtual screening against *Naegleria fowleri* glucokinase (NfGlck).

### ADMET_results_7.xlsx

Contains ADMET (Absorption, Distribution, Metabolism, Excretion, and Toxicity) profiling results for the shortlisted lead compounds.

### homo-lumo-results.xlsx

Contains DFT-based HOMO-LUMO analysis results used to evaluate the electronic properties and molecular reactivity of selected compounds.


These results were used to identify potential glucokinase inhibitors against *Naegleria fowleri* for further investigation.
